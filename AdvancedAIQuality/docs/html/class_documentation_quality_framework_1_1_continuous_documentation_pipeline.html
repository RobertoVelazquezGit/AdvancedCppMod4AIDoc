Detailed Description

Synchronous FIFO mock of a continuous documentation pipeline.

Monitoring is a single simulated scan. No worker thread is started. Scheduling time, priority, patterns and provider settings are metadata only. Lifecycle and processing calls are intended for one controlling thread.
