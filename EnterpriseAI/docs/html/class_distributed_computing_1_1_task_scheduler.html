Detailed Description

template<typename TaskType, typename ResultType>
class DistributedComputing::TaskScheduler< TaskType, ResultType >

Stores simulated workers and executes tasks locally on demand.

Template Parameters
TaskTypeCopyable callable that takes no arguments.
ResultTypeReturn type of the callable, including void.

Futures use deferred execution: get() or wait() executes the task on the calling thread. No network communication or background workers exist.
