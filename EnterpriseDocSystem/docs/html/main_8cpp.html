int main ( )

Runs behavior checks, prints initial metrics and benchmarks the mock.

Uses instance bounds [2, 8], one mock cluster and two alert labels. Checks rejection before deployment, invalid bounds, scaling, rollback, alerts and the blue-green flag. Then performs 100000 timed iterations per case: construction plus deployment, scaling, metric snapshots, alert configuration, blue-green toggling, and scaling plus rollback.

Returns
0 on completion; 1 when a caught standard exception reports failure.
Note
Timings describe local mock operations only. Use Release builds when comparing runs.
