Detailed Description

Coordinates simulated documentation generation for multiple audiences and formats.

No files are read and no AI services are contacted. Scores are fixed at 80/100. All formats, including PDF, contain plain-text placeholders. Instances are not thread-safe.

◆ generateDocumentation()

std::future< DocumentationOrchestrator::GenerationResult > MultiModalDocumentation::DocumentationOrchestrator::generateDocumentation ( const DocumentationRequest & request)

Computes mock documentation immediately and returns a ready future.

Parameters
requestSource label, audiences, formats, provider, and quality threshold.
Returns
A ready future containing the result or a captured exception.

The preferred provider is used if registered; otherwise the first map entry is used. A score below either threshold adds a warning and clears content only if blocking is enabled.

Note
Calling get() rethrows std::invalid_argument for an empty path, no formats, or an out-of-range threshold, and std::runtime_error when no provider is registered. No background task is started, and the future does not retain this object.
