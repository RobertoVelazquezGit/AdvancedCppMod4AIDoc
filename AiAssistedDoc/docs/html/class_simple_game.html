Detailed Description

Manages players and console-based number-guessing rounds.

Targets range from 1 to 100 inclusive. Only exact guesses earn points through makeGuess(). Call endRound() explicitly to finish a round.

Note
State is in memory only and is not thread-safe.

◆ endRound()

void SimpleGame::endRound ( )
inline

Ends an active round, reveals its target and prints player standings.

Does nothing if inactive. Each standing is printed before checking a 200-point threshold: qualifying players advance once and lose all points. No separate level-up notification is printed.

Precondition
For qualifying players, the next level must be representable as int.

bool SimpleGame::makeGuess ( const string & playerName,
int guess )
inline

Checks a guess and prints feedback; exact matches add 100 points.

Parameters
playerNameRegistered player's case-sensitive name.
guessGuessed integer; the range is not validated.
Returns
True for an exact match by a registered player in an active round; false for an incorrect guess, unknown player or inactive game.

An exact match leaves the round active. Repeated exact guesses can earn points until endRound() is called. Incorrect guesses earn no points.

Precondition
On an exact match, adding 100 to the player's score must fit in int.

◆ startNewRound()

void SimpleGame::startNewRound ( )
inline

Generates a target in [1, 100], increments the round and activates play.

Replaces any active round without ending it; retains players and scores. A fresh mt19937 engine is seeded with random_device for each call. This generator is not cryptographically secure.

Precondition
The incremented round counter must be representable as int.
